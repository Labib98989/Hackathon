Copypasta Hunter

Catches AI copy-paste. Forces devs to prove they understand their own code before a PR can merge.

How it works

01. You open a pull request on GitHub.
02. The bot blocks the merge and drops a quiz link in the PR comments.
03. You have 60 seconds to explain your own code — no copy-paste, no switching tabs.
04. Pass the quiz and your PR unlocks. Fail it and the PR stays blocked.
